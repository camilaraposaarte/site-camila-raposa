# Site Camila Raposa

Site da marca Camila Raposa: artista visual e professora de arte em Porto Alegre.

- Site estático (HTML e CSS), publicado pelo GitHub Pages.
- Cores e fontes ficam num lugar só: o bloco `:root` de `assets/css/estilo.css`.
- Fontes: Caprasimo (títulos) e Comfortaa (texto), ambas com licença livre OFL, guardadas em `assets/fonts`.
